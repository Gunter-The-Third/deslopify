# Plain factual prose

Use the [shared workflow](../deslop/SKILL.md) and
[focus rules](../deslop/rules/focus.md) on the supplied target. Keep the
original language. Ask for a target if none is supplied.

Keep facts, mechanisms, evidence, limitations and needed actions. Remove
judgments about importance or interest, reader-directed asides, dramatic
problem setups, selling points, aphorisms and irrelevant detours. Those are
editable framing, not factual claims that must survive the rewrite.

For each sentence, ask what the reader learns or needs to do. Cut sentences
that add neither. When a sentence mixes a fact with framing, state the fact
directly. Do not replace removed hype with softer hype or explanatory filler.
Cut “modest”, “meaningful”, “interesting” and similar evaluations when the
measurement already says what happened. Remove content-free change summaries
and explanations that repeat the mechanism just described.

Preserve protected tokens, operational conditions and real uncertainty.
Check the diff for lost meaning, then read once more for residual commentary.
For supplied text, return only the rewrite. For files, give a brief report.
