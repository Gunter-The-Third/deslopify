# Facts and relevance

Chinese mode selects content by what the reader needs to understand or do.
It keeps the original language. Treat these patterns as framing that can be
removed, while preserving the factual clause and its qualifications.

## Importance narration

> The memory figure is the interesting one. The drop from 1.1 GB to 72 MB is what changes the operational picture.
>
> Peak memory fell from 1.1 GB to 72 MB.

Cut “this is important”, “what really matters”, “a vital improvement” and
“the real story” unless the user needs a supported comparison of priorities.
Give the measurement, mechanism or consequence that supports the decision.
Keep statistical significance and stated requirements.

> The time improvement is real but modest. Peak memory fell from 1.1 GB to 72 MB.
>
> Peak memory fell from 1.1 GB to 72 MB.

If a table gives the timings, leave the comparison to those values. Do not
replace “real but modest” with “modest”, “meaningful” or another judgment.

## Drama and aphorisms

> The old importer loaded the whole file into memory, so a 2 GB file was a gamble.
>
> The old importer loaded the entire 2 GB file into memory.

> Verify duplicate handling before enabling production writes. The guarantee is straightforward, but it is cheap to check and expensive to assume.
>
> Verify duplicate handling before enabling production writes.

Keep concrete failures and required checks. Cut invented stakes and general
lessons that add no evidence or action.

## Reader-directed asides and detours

> If you maintain ingestion jobs, you know the shape of the problem. Harbour imports order records from CSV files.
>
> Harbour imports order records from CSV files.

Cut generic problem scenes, guesses about the reader, obvious explanations
and digressions that do not help answer the task. Keep details needed to use
the tool or interpret a result. Do not compress away preconditions, exceptions
or uncertainty. Do not turn factual prose into unexplained fragments.

> The main change from the old importer is how the file is read. Harbour reads chunks of 8,000 rows.
>
> Harbour reads chunks of 8,000 rows.

Remove a summary that announces the mechanism stated in the next sentence.
